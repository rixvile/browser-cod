# Для следующего разработчика

Перед существенной правкой прочитай **ARCHITECTURE.md** и **AI_GUIDE.md**. Сохраняй публичный контракт между React и игрой. После изменения запускай `npm test` и `npm run build`, затем проверяй затронутую функцию в браузере.

Для редизайна начинай с `UI_INTEGRATION.md`. Настройки баланса и описание карты хранятся отдельно от визуальных моделей. Русские комментарии в исходниках поясняют единицы измерения и владельца каждого состояния.

| Задача | Порядок изменения |
| --- | --- |
| Добавить оружие | Добавь описание в `config/gameplay.ts`, модель в `render/AssetManager.ts`, проверь хоткеи в `player/Input.ts`, индикаторы слотов и экран управления. `Armory` создаёт магазин и резерв по списку конфигураций. |
| Изменить карту | Правь `world/map.ts`. Координаты y относятся к основанию коробки. Проверь спавны, проходы, лестницу и свободное место для корпуса на узлах навигации. Затем обнови таблички и украшения в `render/arena.ts` и `scenery.ts`. |
| Добавить дронов | Обнови `BOT.count`, список начальных и запасных `BOT_SPAWNS`, описание тренировки в меню. Особые правила дрона помести в `ai/Bots.ts`, внешний вид — в `render/AssetManager.ts`. |
| Добавить настройку | Расширь тип, значения по умолчанию и валидацию в `config/settings.ts`. Подключи управление в `SettingsPanel` и потребителя в `Game`, `ArenaView` или `AudioManager`. Тестом покрой старое сохранение. |
| Заменить UI | Передавай данные через `getSnapshot`, команды через `actions`. Прямые обращения к камере, здоровью или DOM canvas из React нарушают контракт. |

### Проверка изменения

1. Запусти `npm test` и `npm run build`. Строгий TypeScript включён в сборку.
2. Запусти `npm run dev`, открой новое окно браузера. Проверь консоль, захват мыши, паузу, продолжение и изменённую механику.
3. Для графических изменений проверь высокий и низкий пресеты, тени и FPS. Для UI проверь клавиатуру, контраст и подписи при узком окне.
4. После стабильного этапа создай отдельный Git-коммит. При необходимости восстановить всю историю воспользуйся командой из README.
