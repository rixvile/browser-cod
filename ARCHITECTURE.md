# Архитектура

TypeScript описывает состояние одного матча. Three.js отображает арену. React отображает снимок состояния и отправляет команды. Направление зависимостей показано ниже.

```text
React → GameClient (состояние + команды) ← Game → Simulation
                                             ↳ ArenaView
                                             ↳ AudioManager
```

Игровая математика и правила не зависят от DOM. Симуляцию можно запустить в тестах Node.js без окна и графического ускорителя. Публичный контракт находится в `src/core/contract.ts`.

## Один кадр

1. `Input` накапливает удерживаемые клавиши и разовые действия. Смещения мыши сразу меняют угол взгляда. При потере фокуса состояние ввода очищается.
2. `Game` измеряет время между кадрами и даёт симуляции шаги по 1/60 секунды. Длительная остановка вкладки ограничивается 0,1 с за кадр. Пауза обнуляет остаток накопителя.
3. `Simulation` передвигает игрока, обновляет арсенал, обрабатывает выстрелы, очки и условия окончания. Одна очередь обновлений обслуживает ботов и возрождение.
4. Типизированные события `shot`, `enemyShot`, `kill`, `hurt` и другие поступают в представление и звук. Математические результаты от этих подписчиков не зависят.
5. `ArenaView` читает положение тел. Она рисует мир, очищает глубину и рисует оружие отдельной камерой. Статические детали объединены, трассеры переиспользуются.
6. Снимки HUD сравниваются не чаще 20 раз в секунду во время игры. Переходы между меню публикуются сразу. React уведомляется только при изменении видимых значений.

## Владельцы данных

| Данные | Владелец |
| --- | --- |
| Режим, настройки, ввод и подписки UI | `core/Game.ts` |
| Таймер, прочность, счёт и возрождение | `core/Simulation.ts` и `player/Player.ts` |
| Незавершённая перезарядка и запас каждого слота | `weapons/Armory.ts` |
| Маршруты, состояния и зрение дронов | `ai/Navigation.ts`, `ai/Bots.ts` |
| Сетка и твёрдое содержимое станции | `world/map.ts`, `world/physics.ts` |
| Камеры, материалы, меши, текстуры и пул эффектов | `render/` |
| Вкладка настроек и содержимое панелей | `ui/` |

Формулы стрельбы и зрения обращаются к общей геометрии. Внешний вид дрона можно заменить, сохранив габариты двух зон попадания. Настройки читаются через валидатор и могут пережить частичное или устаревшее сохранение.
