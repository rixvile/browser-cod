## Состояние и команды

`useSyncExternalStore(client.subscribe, client.getSnapshot)` возвращает стабильный `GameUIState`. В нём есть режим (`menu`, `playing`, `paused`, `results`), запас здоровья и патронов, таймер, счёт, короткие сигналы попаданий, прогресс перезарядки и настройки. Значения для отладочной панели активируются флагом `settings.debug`. Для разных веток HUD можно подставить тестовые снимки в изолированном компоненте.

```tsx
const state = useSyncExternalStore(client.subscribe, client.getSnapshot);
return <button onClick={client.actions.resume}>Продолжить · {state.score}</button>;
```

Подключай кнопки к `GameActions`. Например, `start()` создаёт матч, `resume()` возвращает в текущий, `updateSetting('fov', 80)` меняет поле зрения. `start` и `resume` вызывай непосредственно обработчиком нажатия. Браузеру нужен жест пользователя для захвата мыши и включения звука.

## Слои и фокус

- `#world` содержит единственный canvas, `#root` содержит React. Оба слоя занимают одну область.
- У игрового HUD стоит `pointer-events: none`. Кнопки паузы и захвата мыши возвращают `pointer-events: auto`. Сохраняй это поведение после редизайна.
- Режим и пауза принадлежат движку. Выбранная вкладка меню принадлежит React. Переключение вкладок сохраняет текущий матч.
- Сохраняй контраст на светлом песке и в тёмных проходах. Проверь клавиатурный фокус, длинные русские подписи и высоту окна 600 px.
- После переноса проверь начало, паузу с потерей Pointer Lock, продолжение, перезарядку, возрождение, переключение оружия и сохранение громкости после обновления страницы.
