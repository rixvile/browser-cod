# Relay Shift

Оригинальный однопользовательский браузерный FPS проекта Browser COD. Арена «Кестрел» расположена на ретрансляционной станции в пустынной котловине.

В скачанном архиве открой **PLAY.html** двойным щелчком в Chrome или Edge с WebGL 2. Для этой сборки интернет и установка Node.js не требуются. Кнопка **Начать тренировку** запускает одиночный матч. Исходный проект находится в этой же папке.

## Запуск

Установи Node.js 22.18 или новее. Из папки с `package.json` выполни команды в PowerShell.

```powershell
npm.cmd install
npm.cmd run dev
```

Открой адрес, напечатанный Vite. Для выпуска проекта запусти `npm.cmd test`, затем `npm.cmd run build`. Проверить готовую сборку можно командой `npm.cmd run preview`.

Команда `npm.cmd run portable` заново собирает автономный файл в `release/PLAY.html`. Записи выстрелов встроены в сборку. Авторы и лицензии указаны в `public/third-party.txt`. Для развёртывания на статическом хостинге используй содержимое `dist/`.

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение, обзор | WASD, мышь |
| Бег, прыжок, приседание | Shift, пробел, удерживать C или Ctrl |
| Огонь, прицеливание | ЛКМ, удерживать ПКМ |
| Перезарядка, смена оружия | R, 1–3 или колесо мыши |
| Пауза | Esc или P |

Если встроенное окно ограничивает захват мыши, доступны поворот стрелками и кнопка повторного захвата. Настройки звука, графики и чувствительности сохраняются для текущего адреса браузера.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `src/core/` | Клиент, симуляция, переходы между режимами, контракт UI |
| `src/player/`, `src/weapons/`, `src/combat/`, `src/ai/` | Ввод, перемещение, арсенал, лучи и дроны |
| `src/world/`, `src/config/` | Схема арены, коллизии, баланс и настройки |
| `src/render/`, `src/audio/` | Three.js, модели, камера, эффекты и Web Audio |
| `src/ui/` | Меню, HUD, настройки и CSS-токены |
| `tests/` | Автоматические тесты игровой логики на встроенном runner Node.js |

Технологии проекта — TypeScript, Three.js, React и Vite. Первая версия рассчитана на настольную мышь и клавиатуру. Архив содержит историю стабильных этапов в `history.bundle`. Чтобы восстановить Git-репозиторий, выполни `git clone history.bundle relay-shift`.
